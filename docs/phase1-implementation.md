# 一期补齐与验收追踪

依据 `phase1-requirements-reference.txt` 的第 6 章，以及用户要求保留现有扩展能力。
不移除 X 发布、远端 LLM、已登录 Telegram Web、多对话和插件能力。

## 开始实施时的差距（2026-09-05）

| 项目 | 现状 | 补齐方向 |
| --- | --- | --- |
| 链接发现/下载 | 比特浏览器路径可用，独立入口与筛选不足 | 标准浏览器公开模式、Telegram 公开预览、1–500 条筛选/去重/导出、失败项重试 |
| 素材入库 | 无正式素材库 | resources.db、源文件保留、检查/处理/复检、哈希及视觉近似去重、问题列表 |
| 分析 | OCR/ASR/视觉模型可用 | 入库记录关联、基础评分、策略规则与适配评分、人工复核 |
| 工作台 | 多对话可用，无跨工具任务面板 | 统一八状态、排队/暂停/继续/停止/重试、人工处理、查询记录 |
| 工具箱 | 仅插件管理 | 四个独立工具入口，共用任务/设置，现有扩展保留 |
| 设置 | LLM/窗口有配置 | 素材库/下载目录、分析规则、标签、策略评分、并发配置 |

人像边界：允许检测人物和标注可见特征、人工分组；不实现跨图片自动确认人物身份的生物识别。

## 实施顺序

1. 本地素材库、配置、统一任务记录与调度。
2. 可独立调用的入库检查和分析/评分服务，接入现有媒体插件。
3. 标准浏览器公开发现/下载，保留原 BitBrowser 路径。
4. 工具箱、任务管理和设置 UI，以及 Harness 工具接入。
5. 单元/集成/UI 验证、打包、逐条记录剩余验收限制。没有真实验证的能力不得标记为验收完成。

## 本次已落地（2026-09-06）

- 工作台 UI 参考文档图 4-2：深蓝左栏、浅色对话区、蓝色操作、右侧任务管理；宽窄窗口分别验证，四工具卡片进入独立工具窗口。历史对话/多模态附件/浏览器管理/远端模型入口保留。
- 四个工具入口及 `run_material_task`/`list_material_library`；手工与 Agent 共用业务服务、设置及逐项任务记录。
- 素材任务八状态、完整参数快照、项目级暂停/停止、重试跳过成功项、异常写日志、跨进程执行锁和崩溃恢复；全局视图汇总既有 Agent 任务和素材任务。下载时可读取逐文件速度/字节数/长时间无更新提示，总进度仍按完成项目计算。
- 标准浏览器公开发现原型：公开频道/平台 URL/关键词/账号 ID，媒体类型、时间、严格大于阈值、有效数量 1–500、去重与 TXT/CSV/JSON 导出。缺少日期的记录不会冒充通过时间筛选；可明确选择不限时间。
- 公开 Telegram 具体消息下载、图片/视频与随附文字/元数据、成功文件校验复用；原有 authenticated Telegram Web 和 BitBrowser 下载路径保留。
- `resources.db` 素材库，源文件保留、合格副本 SHA 校验、视觉近似去重、不合格问题记录；采集/入库/分析/使用分轴状态。可预览图片、打开视频、人工复核、重检所选问题、逻辑删除和恢复。
- 入库检查：图片解码/方向/格式、视频完整解码、曝光/清晰度、模型水印检查、受限区域自动修复与复检；模型异常和不确定结果不入库。
- 本机语义分析、分析维度/标签配置、基础质量分、硬筛选/偏好/加权策略分，未配策略保留“待配置”，支持已有分析结果重新评分及人工复核审计。

## 验证与剩余范围

当前属于增量实现，**不标记一期全量验收完成**。

- 初次实现批次测试：核心 262 项、媒体 77 项通过；社媒工具 203 项通过、51 项按环境条件跳过。后续回归见下方各批次记录。入库/任务服务使用隔离数据与模拟模型验证，不是真实模型效果保证。
- 已做工作台、980px 紧凑布局、工具箱、入库窗口离屏截图检查；尚需真实 macOS 与 Windows 分别实机验收。
- 公共站点尚未完成全部登录/匿名对照样本验收。平台动态 DOM、可见日期缺失和反爬可能造成不足量；不能保证标准匿名浏览器在小红书/抖音获取满额。
- 新链接发现窗口已接入标准浏览器/明确选择的 BitBrowser，以及 RPA 滚轮/自动化滚动模式；不表示已验证两种模式在平台上的稳定性差异或防检测能力。
- 新发现路径会等待人工验证，并在验证清除后继续当前调用；比特窗口待人工处理时保留。标准匿名窗口只在当前调用的有界等待期间保留，调用结束会关闭；尚未实现跨调用保留匿名环境和发现游标恢复，不会绕过验证。
- 自定义起止日期、访问间隔和最长运行时间已接入 GUI 与插件；最长运行时间从采集导航开始计算，不含排队/浏览器启动。重名账号列表交互仍待实现，目前需要明确账号 ID 或主页 URL，不擅自选择同名账号。
- 标准公开 Telegram 下载按成功文件恢复，未完成单文件暂不做 Range 续传；已有 Telegram Web 续传实现保留。
- 全局面板通过 TaskCenter 控制素材任务和 Agent 任务；Agent 可从面板停止、选择原任务交回 Harness 续做，尚无原生暂停 worker，不启用该操作。两个任务存储不做强行合并。新的素材任务跨应用重启后可从面板继续，Harness 素材任务 ID 的原地继续工具接口仍待补齐。
- 素材库暂按文件形成资源；同一图文帖聚合多个媒体为一个资源及完整人工编辑字段仍需补齐。已有媒体类型/主题/质量分/策略建议筛选及标签、分析文本、人工分组搜索；视频水印检查使用抽帧，不保证检出所有短暂出现的水印；自动修复效果需实样复核。
- 策略组已提供结构化权重/硬条件/偏好编辑器；主题、分析维度和标签规则仍用 JSON。本地模型版本探测、人工复核结果回填所有派生报告尚未补齐。
- 人像自动跨图身份聚类不实现；保留人物可见特征与人工分组。

## 本轮局部重构

- 保留浅色 UI 与所有已有扩展，拆分四种素材处理器、UI 组件和表现控制器，兼容已有导入路径。
- TaskCenter 统一查询、能力判断与状态复验；Agent 操作精确路由到所属对话，选中任务续做不清空未发送草稿/附件，错误关联的恢复计划不自动执行。
- 任务和素材列表分页，选中项懒加载详情；已迁移数据库初始化与查询不占写事务。策略重算在后台执行，计算与文件复制/哈希移出写事务。
- 按任务保存入库回执、分析所有权/租约；应用崩溃恢复同时处理对应素材状态；成功结果可重放，旧 worker 不能覆盖新租约。暂停/停止不再被记录为模型失败，并修复恢复请求与 worker 清理重叠时丢失的竞态。
- 回归使用临时数据库和模拟模型/浏览器，不触发真实下载或 X 发布。Windows 实机和模型效果验收仍单列，不因重构测试通过而标记完成。
- 本轮核心全量回归 **355 项通过**，包含旧数据库迁移、所有权保护、暂停/恢复竞态、跨对话续做、分页旧记录可达性及关闭窗口后的异常日志。工作台宽/窄布局、工具箱、入库和素材库已做离屏截图检查。
- 创建任务时的本地目录扫描仍在 GUI 线程；Agent 尚无原生暂停。它们不属于本轮已完成项。
- 重构版独立输出至 `dist/refactored/SocialAgent.app`（416 MB），已通过本机签名校验及隔离数据启动检查。原 `dist/SocialAgent.app` 未覆盖，插件未改动；使用新版时需退出旧 Agent 再打开此包。
